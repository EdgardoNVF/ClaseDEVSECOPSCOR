# Documentación microservicio cliente

Se listan las variables de entorno que se utilizan en la app:

- **CLIENT_ID:** Representa el id del app registration de azure entra id

- **APP_SECRET:** Representa la clave temporal de conexión para la app y azure. 

- **TENANT_ID:** Representa el dominio de identidades al que pertenece la app. 

- **KEY_VAULT_URI:** URI del vault secretos en azure. 

- **DB_PORT:** Puerto de la base de datos. 

- **DB_IP:** IP de la base de datos

- **DB_NAME:** Nombre de la base de datos.
